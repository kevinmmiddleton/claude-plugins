# Kevin Middleton's Claude plugins

Free plugins for Claude Code and Cowork (and Codex), all in one catalog. Each one lives in its own repo; this repo just lists them, so one command gets you all of them and anything I make later.

## Install

**Claude Code:**

```
/plugin marketplace add kevinmmiddleton/claude-plugins
/plugin install unpaid-intern@middleton
```

The first line adds this catalog under the name `middleton`. The second installs one plugin from it; swap in any name from the table. To pick up new versions later: `/plugin marketplace update middleton`.

**Codex or ChatGPT:** the same catalog works there too.

```
codex plugin marketplace add kevinmmiddleton/claude-plugins
codex plugin add unpaid-intern@middleton
```

**Cowork and the Claude apps:** open Customize, then Plugins, and add `kevinmmiddleton/claude-plugins` as a marketplace. Or download a plugin file from its own repo's latest release.

## What's here

| Plugin | What it does | Repo |
|---|---|---|
| `unpaid-intern` | A free second brain for work. Hand it your transcripts, docs, tickets, and email; get back your morning briefing, meeting prep, status updates, and follow-ups, in plain files you own | [unpaid-intern](https://github.com/kevinmmiddleton/unpaid-intern) |
| `recruiter-bff` | A recruiter that works for you: role-specific interview guides with a reusable story bank, an apply-or-skip score for any posting, scans when you ask, and a tracker in a plain file you own. Formerly Job Search Agent | [recruiter-bff](https://github.com/kevinmmiddleton/recruiter-bff) |
| `personal-site` | A personal website built through a guided interview, from an editorial backbone to a launch walkthrough that ends live on GitHub Pages | [personal-site](https://github.com/kevinmmiddleton/personal-site) |
| `build-with-claude` | A guide that walks non-technical people through setting up Claude Code with Telegram, so they can build apps from their phone | [build-with-claude](https://github.com/kevinmmiddleton/build-with-claude) |

All of them are MIT licensed and free. More about me, and Office Hours if you want help putting any of these to work: [middleton.io](https://middleton.io).
